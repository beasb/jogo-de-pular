# Jogo Mario Clone

Este é um jogo simples inspirado no Mario, criado como projeto de aprendizado. Desenvolvi este jogo assistindo ao canal **Manual do Dev** no YouTube, onde segui um tutorial passo a passo para criar uma jogabilidade básica, animações e interações.

---

## 🎮 Sobre o jogo

- Plataforma: Navegador web
- Tecnologias: HTML, CSS e JavaScript puro
- Gameplay: Controle um personagem que deve desviar de obstáculos
- Animações simples para pular, andar e colisões
- Game Over com animação personalizada
